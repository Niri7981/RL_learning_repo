## 核心公式

深度 Q 网络的损失函数可以写成：

$$
L(\theta)=\mathbb{E}\left[\left(r+\gamma(1-d)\max_{a'}Q(s',a';\theta^-)-Q(s,a;\theta)\right)^2\right]
$$

这是 DQN 最核心的一行。

**深度 Q 网络损失函数（MSE TD Error）**

- $\theta$：Q 网络的参数，也就是正在被训练的“学生”
- $\theta^-$：目标网络的参数，也就是慢更新的“标准答案副本”
- $Q(s,a;\theta)$：Q 网络对当前状态-动作对的打分，也就是“学生的回答”
- $d$：终止标记。若 episode 真正结束，则 $d=1$，未来价值被切断；否则 $d=0$
- $r+\gamma(1-d)\max_{a'}Q(s',a';\theta^-)$：TD Target，也就是“标准答案”
- 外层期望 $\mathbb{E}$：表示对转移样本取平均；工程上通常用经验回放池随机采样近似

## DQN 到底怎样把这个想法组织成一个能训练的算法？

如果只用一个网络，既让它选动作、算 $Q$ 值，又让它自己生成 TD Target，会怎样？可以用一个具体例子来说明。

**第一步：计算 TD Target。** 假设某个状态下网络预测 $Q(s,a)=5.0$，下一步状态的网络输出 $\max Q(s',a')=8.0$。那么：

$$
\text{TD Target}=r+\gamma\times 8.0=1.0+0.99\times 8.0=8.92
$$

$$
\text{TD Error}=8.92-5.0=3.92
$$

**第二步：梯度下降更新参数。** 网络根据 TD Error 调整参数，把 $Q(s,a)$ 往 $8.92$ 的方向拉。到这里一切都还正常。

**第三步：问题暴露。** 关键在于，$s'$ 的 $Q$ 值也是用同一组参数算的。参数更新后，$\max Q(s',a')$ 也跟着变了，可能从 $8.0$ 变成 $4.0$。下次再算同一个 TD Target 时：

$$
\text{TD Target}'=1.0+0.99\times 4.0=4.96
$$

“标准答案”从 $8.92$ 跳到了 $4.96$，差了将近一倍。网络刚追上 $8.92$，目标又跑到 $4.96$；追到 $4.96$，目标又跑到别的地方。结果就是 $Q$ 值剧烈震荡，甚至发散。

函数逼近、自举、离线策略学习这三件事一旦同时出现，训练就会变得极不稳定。

DQN 的答案是三个组件一起上：

- **Q 网络**：替代表格，给每个动作输出价值估计
- **经验回放**：把连续交互得到的样本打散，让训练 batch 不再只反映最近几步
- **目标网络**：作为 Q 网络的冻结副本，专门用来计算 TD Target；参数每隔 $C$ 步才从 Q 网络硬拷贝一次，在两次拷贝之间保持不动

把这三件事合在一起，才得到通常意义上的深度 Q 网络。

## Q 网络与损失函数

上面说到，只用一个网络会让 TD Target 跟着参数一起动。DQN 的解决方案是维护**两个结构相同但更新节奏不同的网络**：

- **Q 网络**（参数 $\theta$）：负责选择动作和日常训练，每步都被梯度下降更新。这是“学生”。
- **目标网络**（参数 $\theta^-$）：Q 网络的冻结副本，专门用来计算 TD Target。参数每隔 $C$ 步从 Q 网络硬拷贝一次，在两次拷贝之间完全不动。这是“阅卷老师”。

两个网络结构完全相同，区别只在参数更新的节奏。这种设计把“预测”和“生成标准答案”解耦，让 Q 网络在一段时间内面对一个稳定的优化目标。

### Q 网络的架构

Q 网络的训练目标，是让网络输出的 $Q$ 值尽可能接近“真实的” $Q$ 值。但真实的 $Q$ 值本身并不能直接查到，所以我们仍然沿用 Q-Learning 的方式构造训练目标：

$$
\text{TD Target}=r+\gamma(1-d)\max_{a'}Q(s',a')
$$

然后最小化网络输出和 TD Target 之间的均方误差：

$$
L(\theta)=\mathbb{E}\left[\left(r+\gamma(1-d)\max_{a'}Q(s',a';\theta^-)-Q(s,a;\theta)\right)^2\right]
$$

这个公式虽然长，但角色其实很清楚：

|符号|含义（直观理解）|角色|
|---|---|---|
|$\theta$|Q-Network 的参数（正在被训练的网络）|学生|
|$\theta^-$|目标网络的参数（Q 网络的冻结副本）|标准答案|
|$Q(s,a;\theta)$|学生当前的回答|网络预测|
|$r$|这一步实际拿到的即时奖励|眼前落袋为安的分数|
|$d$|是否真正终止|终止时切断未来价值|
|$\gamma(1-d)\max_{a'}Q(s',a';\theta^-)$|从新局面出发、目标网络给出的最高未来分，再打个折|未来最多还能拿多少|
|$r+\gamma(1-d)\max_{a'}Q(s',a';\theta^-)$|TD Target|标准答案|

### 第一块积木：TD Target，也就是标准答案

$$
y=r+\gamma(1-d)\max_{a'}Q(s',a';\theta^-)
$$

TD Target 就是“即时奖励 + 打了折的未来最高分”。如果这一步已经真正终止，$d=1$，未来项会被清零，目标就只剩即时奖励 $r$。注意这里的 $Q$ 使用的是目标网络参数 $\theta^-$，而不是正在被训练的 $\theta$。

### 第二块积木：TD Error，也就是预测和标准答案差了多少

$$
\delta=y-Q(s,a;\theta)=r+\gamma(1-d)\max_{a'}Q(s',a';\theta^-)-Q(s,a;\theta)
$$

TD Error 就是“标准答案减去学生的回答”。在表格方法里，我们直接把 $Q$ 值往 TD Target 的方向挪 $\alpha\delta$；但在神经网络里，我们不能直接改某个 $Q$ 值，只能通过修改参数 $\theta$ 间接影响所有输出。

### 第三块积木：平方，惩罚大错，容忍小错

$$
L(\theta)=\mathbb{E}[\delta^2]=\mathbb{E}[(y-Q(s,a;\theta))^2]
$$

为什么不直接用 $\delta$，而是要平方？主要有两个原因：

- $\delta$ 可能是正也可能是负，直接平均会互相抵消
- 平方会更重地惩罚大误差，逼着网络优先修正最离谱的预测

### 第四块积木：取期望，在所有样本上平均

$$
L(\theta)=\mathbb{E}[(y-Q(s,a;\theta))^2]
$$

外面的 $\mathbb{E}$ 表示“对所有可能的转移 $(s,a,r,s',d)$ 取平均”。

在实践里，我们不可能穷举所有转移，所以通常从经验回放池里随机采样一批来近似这个期望，这也是 SGD 里“随机”的来源。

把四块积木合在一起：深度 Q 网络的训练过程，就是不断从经验回放池采样，计算 TD Target，和网络输出对比，用均方误差算出损失，再通过反向传播更新参数 $\theta$。本质上和表格版 Q-Learning 一样，只不过现在更新的是网络参数，而不是表格里的某一格。

## 经验回放

DeepMind 在 2015 年的 DQN 论文里做过对比实验：不用经验回放时，Atari Breakout 里的智能体会反复学习“把球弹到左侧”的策略，因为连续几百帧球都在左侧弹跳；等球回到右侧时，网络又已经忘了右侧该怎么打，只能重新学。加上经验回放后，一个 batch 里可能同时包含“球在左上角”“球在右侧边缘”“球即将落地”等截然不同的场景，网络才能同时学会应对各种局面。

经验回放（*Experience Replay*）的办法很朴素：把所有经历过的转移 $(s,a,r,s',d)$ 存进缓冲区，每次训练时随机采样一小批。随机采样打破了时间相关性，让梯度方向更稳定、更多样。

### 每一步到底存了什么？

每一次交互，都会产生一条五元组：

|分量|含义|CartPole 例子|
|---|---|---|
|$s$|当前状态|`[0.03, 0.12, -0.05, -0.32]`（位置、速度、角度、角速度）|
|$a$|执行的动作|`0`（左推）|
|$r$|获得的奖励|`1.0`（杆子没倒，每步 `+1`）|
|$s'$|下一状态|`[0.03, -0.05, -0.06, 0.18]`（动作后的新观测）|
|$d$|是否终止|`False`（杆子还在立着）|

回放池就是这样的五元组集合。随着智能体不断交互，池子会逐渐填满。

## 目标网络

Q-Learning 的更新目标是：

$$
r+\gamma \max_{a'}Q(s',a')
$$

在表格方法中，这个目标相对稳定，因为 $Q(s',a')$ 和 $Q(s,a)$ 分别存放在不同格子里，更新一个不会立刻改掉另一个。但在神经网络里，参数是共享的，更新 $Q(s,a)$ 的同时，也可能改掉 $Q(s',a')$。换句话说，网络一边在改自己的预测，一边又把下一步要追的目标也改了。

目标网络（*Target Network*）的解决方案很直接：维护两个网络，一个 Q-Network $\theta$ 用于选择动作和日常更新，另一个目标网络 $\theta^-$ 专门用来计算 TD Target。目标网络参数不参与梯度下降，而是每隔固定步数从 Q-Network 拷贝一次：

```python
if step % target_update == 0:
    target_net.load_state_dict(q_net.state_dict())
```

计算 TD Target 时使用目标网络：

```python
with torch.no_grad():
    td_target = reward + gamma * target_net(next_state).max() * (1 - done)
```

## 从零实现 DQN

前面从概念和公式上拆解了 Q 网络、经验回放和目标网络。现在换一个视角：如果你真的要从零写一个 DQN，思路是什么？

先搭网络，再准备数据，然后定义更新逻辑，最后组装成训练循环。以 CartPole 为例（`state_dim=4, action_dim=2`），一步步来。

### 定义 Q 网络

第一件事：写一个网络，输入状态，输出每个动作的 $Q$ 值。CartPole 的观测是 4 维向量（小车位置、速度、杆子角度、角速度），动作是 2 个离散选择（左推、右推）。所以网络需要把 4 维输入映射成 2 维输出。

```python
import torch
import torch.nn as nn


class QNetwork(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),   # 输入层 -> 隐藏层
            nn.ReLU(),                          # 激活函数
            nn.Linear(hidden_dim, hidden_dim),  # 隐藏层 -> 隐藏层
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),  # 隐藏层 -> 输出层
        )

    def forward(self, x):
        return self.net(x)  # 输出形状: (batch_size, action_dim)
```

#### 为什么是“3 个 Linear，2 个隐藏层”？

```text
输入状态 (state_dim)
  ↓
Linear 1 -> 第 1 个隐藏层 (hidden_dim)
  ↓
Linear 2 -> 第 2 个隐藏层 (hidden_dim)
  ↓
Linear 3 -> 最终输出层 (action_dim)
```

更正式的行业叫法是：

- **输入层**（Input Layer）：通常不计入 Linear 层数量，它只是原始输入特征
- **隐藏层**（Hidden Layers）：夹在输入和输出中间的层；这里 `Linear 1` 和 `Linear 2` 的输出分别对应两个隐藏层
- **输出层**（Output Layer）：最后一层，也就是 `Linear 3`，负责给出各个动作的 $Q$ 值

所以这个架构的标准说法是：**3 层全连接神经网络（3-Layer MLP）**。

#### 为什么 4 维变 2 维还要经过隐藏层？

先修正一个概念：如果你只是想把 4 个输入维度变成 2 个输出维度，数学上**并不需要隐藏层**。一个 `nn.Linear(4, 2)` 就能做到。

但如果没有隐藏层，整个 $4 \to 2$ 的变换就只是一次**线性投影**。面对复杂输入关系时，这会非常弱。

隐藏层加激活函数的作用，就是制造“智力缓冲带”：

- 先用 `nn.Linear(4, 128)` 把低维输入升到高维
- 再用 `ReLU()` 对空间做非线性折叠
- 最后再把高维特征压回 2 维输出

没有隐藏层，网络几乎就失去了拟合复杂非线性关系的能力。

## 隐藏层 vs 卷积层：它们到底都是干啥的？

在实际工程里，这两者是完全不同的数据加工厂。

### 隐藏层（通常指全连接层 Linear / Dense）

- 核心作用：**全局逻辑推理**
- 运作特点：每个神经元都和上一层所有输入相连
- 通俗比喻：像一个统计学家，拿到全部数据后做整体判断
- 缺点：输入一大，参数量就容易爆炸，而且会丢失空间位置信息

### 卷积层（Convolutional Layer，如 `nn.Conv2d`）

- 核心作用：**局部特征抓取**
- 运作特点：拿一个小卷积核在图像上滑动扫描
- 通俗比喻：像一个侦探，拿着放大镜在现场一寸寸找线索
- 优势：保留空间结构，参数量也远小于纯全连接层

### 矩阵乘法到底是怎么算的？

比如 `nn.Linear(4, 128)`，输入是 4 维，输出是 128 维。

- 输入 $\mathbf{X}$：形状 `[1 \times 4]`
- 权重矩阵 $\mathbf{W}$：形状 `[4 \times 128]`
- 运算过程：

$$
\mathbf{Y}=\mathbf{X}\cdot\mathbf{W}
$$

根据矩阵乘法规则，最终得到的是一个 `[1 \times 128]` 的新数组，也就是 128 个输出值，而不是 $128 \times 128$ 个结果。

### 神经网络中的“神经元”到底是什么意思？

如果 `nn.Linear(4, 128)` 输出了一个长度为 128 的数组，那么数组里的每一格 $y_i$，都可以看成一个神经元。

它的数学形式是：

$$
y_i=\text{ReLU}\left(\sum_{j=1}^{4}x_j\cdot w_{ji}+b_i\right)
$$

其中：

- $x_j$：输入的 4 个原始数字
- $w_{ji}$：权重
- $b_i$：偏置
- $\text{ReLU}$：激活函数

所以“128 个神经元”在工程上的潜台词就是：**这一层网络一口气算出了 128 个新变量。**

### ReLU 到底是干啥的？

ReLU（Rectified Linear Unit，整流线性单元）在数学上非常简单：

```python
def relu(x):
    return max(0, x)
```

如果输入是负数，它直接归零；如果输入是正数，它原样保留。

### 定义经验回放

第二件事：准备一个容器存历史经验，训练时随机采样来打破相关性。智能体每走一步就会产生一条转移 $(s,a,r,s',d)$，回放池就是把这些转移都存起来。

```python
import random
from collections import deque


class ReplayBuffer:
    def __init__(self, capacity=10000):
        self.buffer = deque(maxlen=capacity)

    def push(self, state, action, reward, next_state, done):
        self.buffer.append((state, action, reward, next_state, done))

    def sample(self, batch_size):
        batch = random.sample(self.buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)
        return (
            torch.FloatTensor(states),      # (B, state_dim)
            torch.LongTensor(actions),      # (B,)
            torch.FloatTensor(rewards),     # (B,)
            torch.FloatTensor(next_states), # (B, state_dim)
            torch.FloatTensor(dones),       # (B,)
        )

    def __len__(self):
        return len(self.buffer)
```

逐个解释几个实现选择：

- **`capacity=10000`**：CartPole 500 局训练产生数千到数万条转移，`10000` 条大约保留最近几十到一百局。太小经验不够多样，太大则会保留过时经验、拖慢收敛。LunarLander 常见规模是 $10^4$ 到 $10^5$，Atari 常见规模是 $10^5$ 到 $10^6$。
- **`deque(maxlen=capacity)`**：满了自动淘汰最旧元素；比 `list` 的头删更合适。
- **`FloatTensor` 和 `LongTensor`**：状态、奖励等用 `FloatTensor` 参与运算；动作用 `LongTensor`，因为 `gather` 需要整数索引；`dones` 用 `FloatTensor`，因为后面会参与 $(1-d)$ 的乘法。

## 整个演练过程的通俗还原

下面这一段例子我保留原意，只做排版整理。

假设你（学生）现在正在打大 Boss **“广智”**。

### 第一步：样本高度相关的致命后果

你刚进游戏，广智一刀劈过来。因为你连着玩，你脑子里（batch）全是这连续 3 秒钟广智挥刀的画面。

- **灾难**：你的大脑（神经网络）开始钻牛角尖，肌肉记忆疯狂强化“广智右劈”这一种情况。结果广智突然变招一个左踹，你直接傻眼，因为你刚刚把怎么躲左踹的本领全给**覆盖忘光了**。
- **工程解法**：拿录像机（Replay Buffer）。把广智的火刀、冰招、远攻、近战全部录下来，训练时随机抽 32 个不连续的画面（随机 batch）喂给你的脑子。你一下看火刀，一下看左踹，大脑才学会了“泛化”的格斗逻辑。

### 第二步：狗追自己尾巴（第三步暴跌灾难）

你打了一发，广智把你秒了。你（学生）心想：“刚才我预测往左闪避能拿 5 分（$Q=5.0$），结果被打死了。教练告诉我，如果我能活到下一步，下一招判定完美的期望是 8 分（$\max Q(s')=8.0$），所以真正的满分目标应该是 8.92 分（TD Target）。”

- **灾难**：你为了让自己的闪避动作往 8.92 分靠拢，疯狂修改了自己的脑神经（参数更新）。结果因为你动了脑子，你对“下一步广智出什么招”的预判**连带着发生大塌方**，原本以为稳拿的 8 分期望，莫名其妙暴跌变成了 4 分（$\max Q(s')=4.0$）。
- **工程解法**：让背后的高玩教练（目标网络）当植物人。教练在 1000 局以内**绝对不准改脑子**。你（学生）怎么折腾、怎么改参数，算下一个状态的期望时，一律去翻教练脑子里的老账本（永远固定在 8.0 分）。靶子（目标）被死死固定住。打满 1000 局，教练看你进步了，才叹一口气，把你的最新脑回路全量复制给自己（参数同步），升级成新版本的标准答案。

### 第三步：Done（$d$）的硬性拉闸

你被广智最后一记重锤直接砸死，屏幕上亮起了红色的“殁”。这一步，就是 $d=1$（Done）。

- **灾难**：因为你已经死了，游戏结束，后面根本没有所谓的“下一招”了。如果你的脑子不灵光，还在继续算“不知道下一招能不能拿 8 分”，那你的标准答案就会变质。
- **工程解法**：公式里的 $(1-d)$ 变成 $(1-1)=0$。一巴掌把未来的幻象全部扇灭。既然死了，你这一步的目标值就只剩眼前的惨烈奖励（$R=-100$），后面的期望强行归零。大脑因此形成条件反射：只要看到这个死亡动作，后面就是无尽虚无，下次再也不敢这么干。

### 第四步：梯度裁剪的硬性保险丝

广智不仅把你秒了，还疯狂嘲讽你。你气到血压拉满，额头青筋暴起（loss 极大）。你的反向传播引擎（SGD）爆发出了毁天灭地的力量，想一拳把显示器干碎。

- **灾难**：这一拳要是真砸下去，你的手当场骨折，键盘当场报废（参数变成 `NaN`）。你的整个游戏生涯直接原地退役。
- **工程解法**：`clip_grad_norm_` 强行在虚空抓住了你的手腕。虽然你想使出 50 的力气，但规则规定，最终只能把力道等比例压到 10 以内。于是你的手腕只是轻轻抖了一下（微调参数），键盘没坏，显示器没碎，你吸一口气，继续下一局。

## 终极闭环

现在再闭上眼睛想一想这套代码：

1. **`QNetwork`（大脑）**：就是你在面对游戏画面时，各个按键（动作）在你心里的分量。
2. **`ReplayBuffer`（录像带）**：负责把连续的录像打碎成无序集锦，防止你钻牛角尖。
3. **`update`（复盘拧旋钮）**：就是你死盯着录像带里某一个实际踩下的按键（`.gather` 这把镊子），对照着教练不动的参考书（`target_net`），在不砸键盘（梯度裁剪）的前提下，一丝丝修正肌肉记忆的过程。

这就叫深度强化学习。它在工程本质上，很像一个健忘、容易情绪崩溃、也容易钻牛角尖的人类，通过“录像机、冷静的教练、安全护栏”强行把自己驯化成游戏大神的过程。
