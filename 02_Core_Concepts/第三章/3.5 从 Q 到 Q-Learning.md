# 3.5 从 Q 到 Q-Learning

上一节我们讲了 DP、MC、TD 三种价值估计方法。它们共同在做一件事：

**估计状态价值 `V(s)`。**

也就是：从某个状态出发，未来平均能拿到多少回报。

这已经比“只看即时奖励”前进了一大步。它不再问“这一步拿几分”，而是问：

**“从这个局面出发，长期来看值多少分？”**

但控制问题还差最后一步：智能体最终必须**选择动作**。  
只知道一个状态整体值多少，并不能直接回答：

- 现在应该向左还是向右？
- 应该跳还是停？
- 这一刻到底该做哪个动作？

所以，光有 `V(s)` 还不够。  
控制问题真正需要的是：

**在同一个状态下，各个动作分别值多少分。**

这就是动作价值函数 `Q(s, a)` 要解决的问题。

---

## 1. 从状态价值到动作价值

状态价值 `V(s)` 回答的是：

**“这个局面整体好不好？”**

而动作价值 `Q(s, a)` 回答的是：

**“在这个局面下，如果我先做动作 `a`，未来整体会怎么样？”**

也就是说，我们需要比较：

- 在状态 `s` 下，先做动作 `a1`，后面继续行动，平均回报是多少
- 在同一个状态 `s` 下，先做动作 `a2`，平均回报又是多少

只有这样，智能体才知道“这个局面下该选哪个动作”。

---

## 2. 如果模型已知，Q 可以从 V 推出来

如果环境模型已知，我们可以从 `Vπ(s)` 推出动作价值：

![[螢幕截圖 2026-05-16 09.44.25.png]]

这个式子的直觉很简单：

**动作价值 = 先做这个动作得到的即时奖励 + 动作带来的下一状态价值的折扣期望**

也就是说，`Q(s, a)` 不是只看这一步奖励，而是把这一步对未来的影响也一起算进去。

---

## 3. 现实问题：模型通常未知

问题在于，现实任务里我们通常不知道环境模型。

智能体看不到完整的：

- 奖励函数 `R`
- 状态转移概率 `P`

它真正能看到的只有：

- 这一步实际拿到了什么奖励 `r`
- 这一步实际走到了哪个下一状态 `s'`

所以在模型未知时，想用 `P` 和 `R` 直接计算动作价值，往往做不到。

这时更自然的思路就是：

**不要先算，再存；而是像学习 `V(s)` 一样，直接学习每个状态-动作对的价值。**

换句话说，我们直接维护一张 **Q 表**：

- 行是状态 `s`
- 列是动作 `a`
- 每个格子存一个 `Q(s, a)`

---

## 4. 有了 Q，策略就能直接给出

一旦有了 `Q(s, a)`，策略就可以直接从 Q 表里读出来：

![[螢幕截圖 2026-05-16 09.47.15.png]]

也就是：

**在状态 `s` 下，选择 Q 值最大的动作。**

所以 `Q(s, a)` 可以理解为：

- 它是**动作价值函数**
- 在表格问题中，它也可以看成一张**动作价值表**

从这里开始，强化学习就真正从“评价局面”走向了“决定动作”。

---

## 5. 动作和策略不是一回事

这里很容易混淆一个点：**动作（action）** 和 **策略（policy）** 不一样。

- **动作**是某一个具体状态下的一次具体选择  
  例如：在状态 `(0, 0)` 选择“向右走”

- **策略**是一整本全局规则手册  
  它规定了：在任意状态下，应该选择什么动作

写成数学形式，策略 `π(s)` 表示一个从状态到动作的映射规则。

所以可以把它们区分成：

- action：眼下这一脚怎么迈
- policy：所有局面下都怎么迈

大白话一点：

**action 是做一道具体的题，policy 是掌握一整类题的做法。**

---

## 6. 贝尔曼最优方程：Q 的最优形式

先回到最优动作价值的直觉。

`Q*(s, a)` 表示：

**在状态 `s` 先执行动作 `a`，然后从下一步开始始终都做最优选择时，最终能得到的期望回报。**

注意这里有个关键点：

- 第一动作 `a` 已经指定，不能再改
- 真正的“最优选择”发生在到达下一状态 `s'` 之后

到了 `s'` 以后，如果我们已经有正确的最优 Q 表，就应该选择让 `Q*(s', a')` 最大的那个动作。

这就是 **Q 的贝尔曼最优方程** 的核心直觉：

**当前动作的价值，等于当前奖励，加上下一状态最优动作价值的折扣回报。**

---

## 7. Q-Learning：模型未知时，直接学 Q

如果模型未知，智能体拿到的不是完整环境模型，而只是一步经验：

```text
(s, a, r, s')
```

这就是 Q-Learning 的出发点。

它不去显式求 `P` 和 `R`，而是利用每次真实经历，直接更新 Q 表。

Q-Learning 的 target 写成：

```text
target = r + gamma * max_a' Q(s', a')
```

然后再用它去更新当前格子：

```text
Q(s, a) <- Q(s, a) + alpha * [target - Q(s, a)]
```

所以 Q-Learning 的本质是：

**用一步真实奖励，加上下一状态“当前最好的动作价值”，来修正当前动作价值。**

---

## 8. 一个最小例子：Frozen Lake 风格的单步更新

我们用一个最简单的表格环境来理解这个更新过程。

### 1. 初始设定

- 智能体站在左上角 `(0, 0)`
- Q 表一开始全是 0
- 智能体这一步选择“向右”，走到了 `(0, 1)`

### 2. 现实反馈

当它走到 `(0, 1)` 后，发生了两件事：

1. 它拿到了即时奖励 `r = -1`
2. 它向前看，发现新状态 `(0, 1)` 对应的所有动作价值目前都是 0

所以：

```text
max_a' Q((0,1), a') = 0
```

如果折扣因子 `γ = 0.9`，那么这一步的 target 就是：

```text
target = r + gamma * max_a' Q((0,1), a')
       = -1 + 0.9 * 0
       = -1
```

直觉上，这表示：

**“从 `(0,0)` 往右走这一脚，目前看来不值钱，它大概值 -1 分。”**

### 3. 不是一步改死，而是慢慢挪过去

Q-Learning 不会直接把旧值改成 `-1`，而是只迈一小步。

假设学习率 `α = 0.1`，旧值是 0，那么更新就是：

```text
Q((0,0), 右) = 0 + 0.1 * (-1 - 0) = -0.1
```

也就是说，这一次经历只让它学到一个很小的教训：

**“从起点往右走，比我原来以为的更差一点。”**

---

## 9. Q-Learning 的底层直觉

这一类更新有三个非常重要的特点：

### A. 局部修改

每次更新，只会修改当前经历到的那一个格子：

`Q(s, a)`

智能体并不会因为一次更新就突然“全局开悟”。

### B. 吃一堑长一智

它只是把某一次具体尝试的结果记下来：

- 这一步更好还是更差
- 应不应该更愿意再做一次

### C. 信息会沿路径反向传播

虽然每次只改一个格子，但经过大量单步更新后，奖励信息会沿着轨迹一步步向前传播。

你可以把它想成“水波纹”：

- 终点奖励
- 掉坑惩罚
- 危险区域

这些信息会通过不断更新，慢慢传回更早的状态和动作上。

最后整张 Q 表就会被逐渐填满。

---

## 10. 训练时怎么选动作：探索与利用

到这里会出现一个非常现实的问题：

**如果一开始 Q 表全是 0，智能体怎么选动作？**

如果它永远只选当前 Q 值最大的动作，那几乎学不会东西。

比如：

- 它从起点往右走了一次，得到负奖励
- 于是这个动作对应的 Q 值变成 `-0.1`
- 剩下没试过的动作还是 `0`

如果它此后完全贪婪，就可能永远回避这条路，缩在起点附近打转，再也探索不到真正的终点。

所以训练时必须加入探索。最经典的做法就是：

## 11. epsilon-greedy

`ε-greedy` 的规则是：

- 以 `1 - ε` 的概率，选择当前 Q 值最大的动作
- 以 `ε` 的概率，随机探索一个动作

于是：

- 大部分时候它在利用当前已有知识
- 少部分时候它在试新路、踩新坑、收集新信息

这就是强化学习里经典的 **exploration vs. exploitation**。

---

## 12. Q-Learning 和 SARSA 的分野

Q-Learning 和 SARSA 的差异，核心不在于“它们都在更新 Q 表”，而在于：

**它们对未来那一步到底按什么策略来估值。**

### Q-Learning

Q-Learning 的 target 是：

```text
r + gamma * max_a' Q(s', a')
```

也就是说，它假设：

**下一步开始，我总能选到最好的动作。**

所以它学的是：

**最优策略的价值**

这就是 **Off-Policy（异策略）** 的核心味道：

当前行为里可以有探索，但更新时参考的是“理论上最优会怎么走”。

### SARSA

SARSA 则不同。它更新时会用“下一步实际又选了哪个动作”来算 target。

也就是说，它学的是：

**在当前行为策略下，我未来真的会怎么走。**

如果当前策略还带着探索，那么它未来就可能继续手抖、继续乱走。SARSA 会把这种风险一起算进价值。

所以 SARSA 学的是：

**当前行为策略的价值**

这就是 **On-Policy（同策略）**。

---

## 13. 两者的直觉区别

两种算法的世界观可以概括成：

- **Q-Learning**：假设未来会做到最优，所以更激进
- **SARSA**：承认未来还会继续探索，所以更保守

这会带来一个很有意思的后果：

- Q-Learning 更容易学出“贴着风险边界走的最短路”
- SARSA 更容易学出“绕开风险区的稳健路径”

比如经典的 cliff walking 场景里：

- Q-Learning 可能贴着悬崖边走，因为那是理论上的最短路径
- SARSA 会更愿意绕远一点，因为它知道探索时手抖可能直接摔下去

---

## 14. 核心区别对照

| 维度 | Q-Learning（Off-Policy） | SARSA（On-Policy） |
| --- | --- | --- |
| 学的是什么 | 如果未来每一步都做到最优，现在值多少 | 如果未来继续按当前策略行动，现在值多少 |
| 对探索的态度 | 更新时忽略探索带来的风险 | 更新时把探索风险算进去 |
| 典型风格 | 激进、短路径、高风险 | 稳健、绕路、低风险 |
| 更适合什么阶段 | 训练结束、探索关闭后执行最优策略 | 训练过程中或本身带随机性的环境 |

---

## 15. 小结

这一节从状态价值 `V(s)` 走到了动作价值 `Q(s, a)`，也就从“评价局面”走到了“学习怎么选动作”。

可以把主线记成：

1. `V(s)` 只能告诉我们“这个状态整体值不值钱”
2. 控制问题真正需要的是 `Q(s, a)`，也就是“这个状态下某个动作值不值钱”
3. 如果模型已知，可以从 `V` 推出 `Q`
4. 如果模型未知，就直接学习 Q 表
5. Q-Learning 用一步经验 `(s, a, r, s')` 更新当前动作价值
6. 为了学到真正有用的 Q 表，训练时必须兼顾探索与利用
7. Q-Learning 和 SARSA 的关键差别，在于它们对“未来动作”采用了不同假设

如果只记一句话，可以记成：

**Q-Learning 学的是“如果未来都最优，现在该值多少”；SARSA 学的是“如果未来还按当前策略走，现在该值多少”。**
