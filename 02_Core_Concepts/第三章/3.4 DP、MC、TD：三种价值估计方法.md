# 3.4 DP、MC、TD：三种价值估计方法

在有限状态问题里，我们常常先维护一张**价值表**：给每个状态存一个当前的价值估计 `V(s)`。

| 状态 | 当前价值估计 |
| --- | --- |
| S | 0 |
| M | 0 |
| G | 0 |

学习价值函数，本质上就是不断修改这张表。真正的问题不是“价值函数定义是什么”，而是：

**每次应该把表里的某个值改成什么？**

这一节要讲的 DP、MC、TD，本质上都是在回答这个问题。它们的差别不在于“要不要更新”，而在于：

**这次更新时，目标值从哪里来。**

---

## 1. 核心任务：价值估计

在强化学习里，我们想知道：如果当前处在状态 `s`，并继续按策略 `π` 行动，未来平均能拿到多少折扣回报？这个量就是状态价值 `Vπ(s)`。

为了估计它，常见有三条路线：

### A. 动态规划（Dynamic Programming, DP）

可以把 DP 理解成一种“**模型已知时的全量计算**”。

- **前提**：知道环境模型，也就是状态转移概率 `P` 和奖励函数 `R`
- **做法**：直接用贝尔曼期望方程，对所有可能动作和所有可能下一状态求期望
- **特点**：不需要真实采样，而是在“脑子里”把所有分支都算一遍

所以 DP 像是一种“上帝视角”的方法：只要模型完整，就能直接算出应该往哪里更新。

### B. 蒙特卡洛（Monte Carlo, MC）

MC 的思路和 DP 相反：**既然不知道模型，那就去环境里真实跑一遍。**

- **前提**：不知道环境模型
- **做法**：完整跑完一条轨迹，等 episode 结束后，用真实回报 `Gt` 反推轨迹中每个状态的价值
- **特点**：目标是真实采样得到的，所以直观、无偏，但波动较大

MC 像“事后算总账”。它不提前推演，只在一局结束后回头看：这一路到底值多少分。

### C. 时序差分（Temporal Difference, TD）

TD 介于两者之间。它既不像 DP 那样知道完整模型，也不像 MC 那样必须等整局结束。

- **前提**：不知道环境模型
- **做法**：每走一步就更新一次，用“即时奖励 + 下一状态当前估计值”来修正当前状态
- **特点**：更新及时、方差更低，是现代强化学习里最常用的价值更新思路

TD 的核心更新公式是：

```text
V(st) <- V(st) + alpha * [rt+1 + gamma * V(st+1) - V(st)]
```

其中中括号里的部分就是 **TD Error**，表示：

**“刚走完这一步后，我发现现实和我原来的估计之间差了多少。”**

---

## 2. 三种方法的共同骨架

虽然 DP、MC、TD 的目标值来源不同，但它们都能写成同一个更新框架：

```text
V(s) <- V(s) + alpha * [target - V(s)]
```

这里：

- `V(s)` 是旧估计
- `target` 是这一次想靠近的新目标
- `alpha` 是学习率，控制更新步幅

所以三者真正的区别只有一句话：

- DP：`target` 来自模型展开后的期望
- MC：`target` 来自整条真实轨迹的最终回报
- TD：`target` 来自“一步奖励 + 下一状态旧估计”

---

## 3. DP：已知模型时，直接算期望

![[螢幕截圖 2026-05-15 20.07.37.png]]

DP 的目标值来自贝尔曼期望方程。它的含义是：

- 外层对动作按策略 `π(a|s)` 加权
- 内层对下一状态按环境转移概率 `P(s'|s,a)` 加权

也就是说，DP 会把“当前状态下所有可能发生的下一步”全部考虑进去，再求平均。

下表是这个目标值里各个符号的含义：

| 符号 | 含义 |
| --- | --- |
| `target_DP(s)` | 这次准备写入状态 `s` 的目标值 |
| `a` | 当前状态下可能采取的动作 |
| `π(a|s)` | 在状态 `s` 选择动作 `a` 的概率 |
| `R(s,a)` | 执行动作 `a` 后获得的即时奖励 |
| `s'` | 可能到达的下一状态 |
| `P(s'|s,a)` | 执行动作 `a` 后到达 `s'` 的概率 |
| `Vk(s')` | 第 `k` 轮旧表中，对下一状态 `s'` 的价值估计 |
| `γ` | 折扣因子 |

如果把它展开成分支表，可以更直观地看出它在做什么：

| 要更新的状态 | 右走分支 | 左走分支 | 加权后写入 |
| --- | --- | --- | --- |
| `S` | `0.8 * [-1 + V_old(M)]` | `0.2 * [-2 + V_old(S)]` | 新的 `V(S)` |
| `M` | `0.8 * [-1 + V_old(G)]` | `0.2 * [-2 + V_old(S)]` | 新的 `V(M)` |

对应的价值表更新过程可以写成：

| 轮次 | `V(S)` | `V(M)` | `V(G)` |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0 |
| 1 | -1.2 | -1.2 | 0 |
| 2 | -2.4 | -1.44 | 0 |
| 3 | -2.832 | -1.68 | 0 |
| 收敛 | -3.375 | -1.875 | 0 |

这里 `G` 没有继续往后展开，是因为它是终止状态。终止状态之后没有未来回报，所以通常把它的价值固定为 0。

DP 的优点是精确、稳定，但代价也很明确：**你必须知道完整模型。**  
这在很多真实问题里做不到，所以它更像理论基准，而不是大规模 RL 的常规做法。

---

## 4. MC：不知道模型，就用整局真实回报

蒙特卡洛（MC）是第二种更新价值的方法：

**不知道环境模型，就用一条完整轨迹的真实回报来当目标。**

DP 需要知道 `P(s'|s,a)` 和 `R(s,a)`，才能把所有分支展开求期望。MC 放弃了这个前提，不再尝试枚举“所有可能会发生什么”，而是直接进入环境，按策略真实地跑完一局。

等轨迹结束后，从时刻 `t` 开始往后的完整折扣回报：

![[螢幕截圖 2026-05-15 20.37.36.png]]

就可以作为这个状态的目标值来更新：

```text
V(St) <- V(St) + alpha * [Gt - V(St)]
```

MC 的直觉很简单：

- 不去猜未来所有可能性
- 只看这一次真实经历最后到底拿到了多少

所以它的优点是：

- 不需要环境模型
- 目标值来自真实回报，概念上很干净

但缺点也很明显：

- 必须等 episode 结束才能更新
- 一条轨迹可能受运气影响很大，所以方差较高

因此 MC 更像“整局复盘之后再记账”。

---

## 5. TD：走一步就更新

TD（Temporal Difference）是第三种价值更新方法，也是最贴近现代强化学习实践的方法。

它的关键想法是：

**不等整局结束，只要刚走了一步，就立刻用这一步的信息来修正当前估计。**

![[螢幕截圖 2026-05-15 20.47.04.png]]

假设初始价值表仍然全为 0，学习率取 `α = 0.5`。这时每一步都按下面的模板更新：

```text
新值 = 旧值 + 0.5 * (TD目标 - 旧值)
```

其中 TD 目标是：

```text
r + gamma * V(s')
```

也就是说，TD 用“**这一步真实拿到的奖励**”再加上“**下一状态当前的价值估计**”，来近似完整未来回报。

于是 TD Error 可以写成：

```text
delta = [r + gamma * V(s')] - V(s)
```

它表示：

- 如果 `delta > 0`，说明这一步之后的现实比原来想的更好，当前状态价值应该上调
- 如果 `delta < 0`，说明现实比预期差，当前状态价值应该下调

TD 的优点是：

- 不需要模型
- 不用等 episode 结束
- 更新更频繁，方差通常比 MC 更低

但它也不是完全“真实”的，因为目标里的 `V(s')` 本身也是估计值，所以 TD 会引入一定偏差。

---

## 6. 三种 target 的信息条件

从信息条件上看，DP、MC、TD 其实是一条逐步弱化的链：

![[螢幕截圖 2026-05-15 20.55.42.png]]

| 方法 | target 从哪里来 | 需要什么信息 | 特点 |
| --- | --- | --- | --- |
| DP | 模型展开后的期望 | 完整环境模型 `R, P` | 最精确，但要求最高 |
| MC | 一条完整轨迹的真实回报 `Gt` | 真实采样轨迹 | 无偏，但必须等结束 |
| TD | `r + γV(s')` | 一步采样 + 旧价值表 | 更新快，但带偏差 |

换句话说：

- DP 是“我全知道，所以我直接算”
- MC 是“我不知道模型，但我能跑完整一局”
- TD 是“我连整局都不等，先用一步信息边走边改”

---

## 7. 关系图：三者都在逼近贝尔曼思想

![[螢幕截圖 2026-05-15 20.55.53.png]]

这三种方法虽然实现路径不同，但它们都服务于同一个核心思想：

**当前状态的价值，可以由即时奖励和未来价值来刻画。**

区别只在于，“未来价值”到底怎么得到：

- DP：由模型精确求期望
- MC：由完整真实回报直接给出
- TD：由下一状态的旧估计近似替代

---

## 8. 小结

这一节讨论了三种价值估计方法：

1. `Vπ(s)` 表示从状态 `s` 出发，并继续按照策略 `π` 行动时的期望折扣回报。
2. DP 假设环境模型已知，直接使用贝尔曼期望方程对所有动作和下一状态求平均。它精确稳定，但现实中往往拿不到完整模型。
3. MC 不需要模型，而是用完整轨迹的真实回报 `Gt` 更新价值。它目标无偏，但必须等 episode 结束，而且方差较大。
4. TD 也不需要模型，并且每走一步就能更新。它使用 `r + γV(s')` 作为目标，更新更及时、方差更低，但因为目标里含有估计值，所以会引入偏差。
5. DP、MC、TD 的共同核心都是贝尔曼思想：当前价值由即时奖励和未来价值共同决定。

如果只记一句话，可以记成：

**DP 用模型算，MC 用整局算，TD 用一步算。**
